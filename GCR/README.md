# GCR — Governance, Compliance, Risk

GCR is the control layer of AETHIEA.

It enforces:
- lane separation
- access boundaries
- exposure control
- execution constraints

Zones:
- VAULT      → private, non-disclosive, ownership truth layer
- DOOR       → structured interface (legal, business, B2B)
- WINDOW     → public output (content, audience-facing)
- HABITAT    → execution environment (devices, local system)
- PEEP_HOLE  → observation without interaction

Invariant:
DON'T MINGLE

No routing may occur without valid domain + GCR zone alignment.
