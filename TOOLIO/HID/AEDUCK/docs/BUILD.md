# AEDUCK Build Recipe

AEDUCK is the Pico-class HID component.

Authority:
AEUSB holds manifests, scripts, payload definitions, and receipts.

Heavy:
AE320 holds firmware cache, builds, exports, and logs.

Hardware class:
Raspberry Pi Pico / Pico W / HID-capable microcontroller.

Route:
AEUSB -> AEDUCK payload definition -> device firmware -> Corp-O receipt.
