# AEBUNNY Build Recipe

AEBUNNY is the Pi Zero-class USB gadget component.

Authority:
AEUSB holds manifests, scripts, payload definitions, and receipts.

Heavy:
AE320 holds images, SD card backups, builds, exports, and logs.

Hardware class:
Raspberry Pi Zero / Zero 2 W / USB gadget-capable Linux board.

Route:
AEUSB -> AEBUNNY payload definition -> gadget image/config -> Corp-O receipt.
