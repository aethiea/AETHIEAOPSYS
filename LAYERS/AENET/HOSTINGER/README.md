# HOSTINGER // AENET PROVIDER LANE

Hostinger is an external provider lane.

AEUSB carries:
- wrapper
- policy
- config template
- receipts
- routing pointers

AEXHB / AE320 carries:
- memory
- backups
- exports
- provider notes
- mutable working data

Rules:
- No Hostinger password in Git.
- No hPanel credential in Git.
- No API token in Git.
- No USB port, drive letter, or /mnt path is authority.
- Resolve AEUSB by .aeth_root.
- Resolve AEXHB by AE320GB_HEAVY_BODY / .aexhb_root / .aeth_heavy_root.
- Host executes. AEUSB carries. AEXHB carries mass.
