# AENET / Tailscale Lane

Tailscale is classified as AENET mesh-network capacity.

Rules:
- TOOLIO/bin may carry callable binaries.
- Host executes the tunnel.
- AEUSB carries wrappers, doctrine, and redacted receipts.
- Tailnet identity, auth keys, machine keys, sockets, and state DB are runtime secrets.
- Runtime state belongs under RUN/TAILSCALE and must not be committed.
- No auth keys in Git.
- No Tailscale state DB in Git.
