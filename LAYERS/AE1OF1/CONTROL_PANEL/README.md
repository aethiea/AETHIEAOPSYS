# AE1OF1 Control Panel

The Control Panel is an operator-gated component of AE1OF1.

It provides controls and readouts for:

- APT package-state inspection
- AESOFT callable-capacity inspection
- governed metabolism submission
- metabolism job status

Control route:

AE1OF1 Control Panel
→ AÆ interpretation
→ ÆBSTRACTION
→ UÆR placement
→ AÆR authority gate
→ EXECUTION
→ AERAG proof and receipts

The Control Panel is an interface component. It does not become the
metabolism engine, grant itself execution authority, or create another
AETHIEAOPSYS body.
