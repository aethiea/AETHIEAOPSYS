AE1OF1 is the AETHIE 1of1 HUD and operator-interface layer.

### HUD

- displays system state
- translates system status
- surfaces operator readouts
- supports interface clarity

### Control Panel

- presents operator-gated controls
- inspects APT package state
- inspects AESOFT callable capacity
- submits material to governed metabolism
- displays metabolism status
